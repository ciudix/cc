# CIUDIX — Centro comercial digital

Landing estático de CIUDIX con pasillo comercial interactivo, buscador, filtros por categoría y fichas de marcas.

## Primeras marcas incluidas
- CookieScape: cortadores para galletas y moldes de silicona.
- Creation · DJ Edgar: DJ, sonido, iluminación y animación para eventos.
- Muebles El Madero: muebles, colchones y bases cama.
- La Casa del Ebanista: muebles, colchones y bases cama.

## Estructura
- `index.html`: contenido y estructura.
- `css/style.css`: estilos responsive y pasillo en perspectiva.
- `js/app.js`: vitrinas, búsqueda, filtros, favoritos y ventanas de detalle.
- `assets/ciudix-logo.png`: logo CIUDIX.
- `assets/cookiescape-vitrina.jpg`: imagen de vitrina CookieScape.
- `assets/creation-dj-edgar.jpg`: pieza visual de Creation · DJ Edgar.

## Cómo probar
Abre `index.html` en un navegador moderno. Para publicar en GitHub Pages, sube todo el contenido de esta carpeta conservando las rutas relativas.

## Contacto
Los botones de contacto general y las fichas de las marcas abren WhatsApp de CIUDIX (`+57 318 447 2253`) con un mensaje contextual. No se inventaron números individuales de las marcas.

## Consideraciones
Los nombres, descripciones y líneas de productos se basan en la información disponible. Los productos de las fichas son categorías ilustrativas, no inventario confirmado; no se muestran precios, stock, calificaciones ni horarios no confirmados. Las imágenes de muebles y productos de apoyo se cargan desde Unsplash. Para producción, sustituirlas por fotografías autorizadas de cada negocio y confirmar contactos, direcciones, horarios y catálogos reales.

Este frontend no incluye base de datos, administración de vitrinas, inventario sincronizado ni pasarela de pago.


## Vitrinas incluidas en esta versión

Marcas iniciales: CookieScape, Creation · DJ Edgar, Muebles El Madero, La Casa del Ebanista y DUCSOFT Technologies.

Vitrinas demostrativas: Sazón de Casa (restaurante), Todo a Diez Mil (variedades) y TecnoPunto (tecnología). Estas tres vitrinas son ejemplos ficticios para mostrar categorías y experiencia; sus productos, precios, horarios y datos de contacto no representan comercios reales. DUCSOFT Technologies es una marca propia del equipo CIUDIX.

El contacto de los negocios aún usa el WhatsApp general de CIUDIX hasta que se configuren los números individuales.


## Ampliación del pasillo — 25 vitrinas
Incluye CookieScape, Creation · DJ Edgar, Muebles El Madero, La Casa del Ebanista, Sazón de Casa (demo), Todo a Diez Mil (demo), TecnoPunto (demo), DUCSOFT Technologies, Electricolombia, Textura y Arte Analy y 14 marcas demostrativas adicionales de moda, belleza, mascotas, papelería, deportes, ferretería, juguetería, calzado, accesorios, cafetería, panadería, bienestar, floristería, automotriz y servicios.
